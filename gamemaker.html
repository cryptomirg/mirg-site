A real example

This is a real session, not a mock-up: the request as it was typed, and what the agent did.

Make the player move twice as fast and add a score that goes up over time
  1. Opened an existing GameMaker project, a cover shooter made from one of GameMaker's own templates
  2. Read the project's objects to find how the player moves and where the score is kept
  3. Found that the player in this game does not walk: they duck behind cover and pop up to shoot. So it doubled the speed of that, and said so, instead of pretending there was walking to speed up.
  4. Found the game already had a score for defeating enemies. Kept it, and added 10 points a second while playing, but not during the countdown, while paused, or after winning or losing.
  5. Said plainly that it had not run the game, and asked for Play to be pressed in GameMaker

The first message took 58 seconds.

The result. Both changes worked when the game was run from GameMaker. Each is a single number in the code that the agent pointed to, so it is easy to adjust.

How it works with GameMaker

  • Mirg reads and edits the GML code in your project. GameMaker picks up the changes.
  • The game is run from GameMaker itself, so the agent cannot see or play it. Tell it what you see.
  • Start the project in GameMaker, from a template or from scratch, then open its folder in Mirg. GameMaker's project files are intricate, and it is the best tool for creating them.

What you need

  • GameMaker, free for non-commercial use, with a GameMaker account.

Mirg lists what is installed and what is missing under "See what's installed" on its home screen. If you ask for a GameMaker game without the tools for it, it tells you what to get and offers to build a web game instead.

Good to know

  • This is the lightest of Mirg's integrations: it edits code, and GameMaker does the rest.
  • For a game built from nothing by the agent, a web game or Godot is a better fit.

Questions

Can Mirg create a GameMaker project from scratch?

It is better to start the project in GameMaker, from a template or empty, and then open it in Mirg. Mirg edits the code in an existing project.

Can the agent run my GameMaker game?

No. You run it from GameMaker. The agent edits the GML code and relies on you to say what happened.

What language does it edit?

GML, GameMaker's own language, in your project's .gml files.
