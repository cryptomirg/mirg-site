A real example

This is a real session, not a mock-up: the request as it was typed, and what the agent did.

Make a Godot game: a top-down space shooter where I fly a ship, shoot asteroids, and the score goes up
  1. Wrote the project file, the main scene and four scripts: the ship, the bullets, the asteroids and the game itself
  2. Had Godot check every script for errors
  3. Exported the game and started it in the Game tab
  4. Flew the ship while holding fire, and read the score
  5. Changed one thing it noticed, then played again to confirm

The first message took 1 minute 29 seconds.

The result. A playable Godot shooter in a minute and a half, with no errors: asteroids break apart, the score climbs. The same project then ran in its own window, where the agent looked at it and played it too.

How it works with Godot

  • The agent writes Godot's own text formats: project.godot, .tscn scenes and GDScript. The project opens in the Godot editor like any other.
  • Mirg exports the game for the web with Godot itself and shows it in the Game tab, where the agent can take screenshots and press keys.
  • A Godot game can also run in its own window. The agent can look at and play that too, once macOS has been given permission.
  • Projects in C# run in their own window, since Godot cannot export C# to the web.

What you need

  • Godot 4 and its web export templates. Mirg installs both for you with one button, from Godot's official release, and checks the download against Godot's published checksum.

Mirg lists what is installed and what is missing under "See what's installed" on its home screen. If you ask for a Godot game without the tools for it, it tells you what to get and offers to build a web game instead.

Good to know

  • The first export of a project takes longer than later ones.

Questions

Do I need to install Godot myself?

No. Mirg can download and install Godot and its web export templates for you, from Godot's official release. If Godot is already installed, Mirg uses it.

Can I open the project in the Godot editor?

Yes. It is a normal Godot 4 project: scenes, scripts and a project file in a folder on your computer.

Does it use GDScript or C#?

GDScript by default, which is what lets the game play inside Mirg. C# projects work too and run in their own window.
