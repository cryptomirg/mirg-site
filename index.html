How it works

No engine to learn and nothing to set up. If you can describe it, you can start.

1 · Describe

Say what you want

Type it or say it out loud. "A platformer where a fox collects coins and avoids spikes." That is enough to begin.

2 · Watch it get built

The agent does the work

It writes the code, starts the game, looks at the screen and presses the keys itself to make sure things work before telling you it is done.

3 · Play and change

Keep going

Play it right there. Ask for a double jump, a new enemy, real artwork. Every message has a Restore button, so nothing is permanent.

What makes it different

Most AI tools hand you code and hope. Mirg runs the game and checks its own work.

It plays what it builds

The agent takes screenshots, presses keys, taps the screen and reads the score, then fixes what is broken. It also tells you what it could not check.

The game is always in front of you

Game in one tab, code in another, files and art in a third. Look under the hood only if you want to.

Phone games included

Preview on an iPhone or Android screen with real touch input, then turn the game into an app that runs in the iOS Simulator or Android emulator.

Art on request

Starts with clean placeholder shapes so you can play straight away. Ask for real artwork when you are ready.

Pick your model

Claude, GPT and Gemini models, with a simple control for how hard the model thinks. No API keys to manage.

Your files, on your computer

Projects are ordinary folders on your Mac. Open them in any editor, put them in version control, take them anywhere.

Works with the engines people use

Web, phone and Godot games play inside Mirg, where the agent can see and test them. Other engines work if you have them installed, and Mirg tells you what is missing and how to get it. Every one below has been run for real.
