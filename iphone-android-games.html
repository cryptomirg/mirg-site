A real example

This is a real session, not a mock-up: the request as it was typed, and what the agent did.

Make it work on phones with touch controls
  1. Added on-screen buttons and made the layout fit a phone held sideways
  2. Switched the Game tab to an iPhone preview and played the game by touch
  3. Asked to make an iOS app: packaged the game, built it with Xcode and launched it in the iOS Simulator
  4. Noticed two things that only looked wrong on iOS, button symbols drawn as emoji and a line of text running off the edge, and fixed both
  5. Asked for Android: built it, launched it in the emulator, hid the system bars for true full screen and tapped through the title screen

The first message took 41 seconds for touch controls, 3 minutes 28 seconds for the iOS app, 1 minute 26 seconds for Android.

The result. One game, running as a web game, an iPhone app and an Android app, from the same code. The Xcode project is in an ios folder and the Android Studio project in an android folder.

How it works with iPhone and Android

  • The Game tab can show the game on an iPhone, iPad or Android screen, with touch input, in either orientation.
  • Phone games are written with web technology and wrapped as real, installable apps. The agent says so plainly, since many people expect an iPhone app to be written in Swift.
  • On the Android emulator the agent can tap the screen itself. On the iOS Simulator it can look but not tap, and it tells you that.
  • Publishing to the App Store or Google Play is your step, from Xcode or Android Studio, with your own developer account.

What you need

  • For the phone preview: nothing.
  • For an iOS app: Xcode, free from the Mac App Store.
  • For an Android app: Android Studio, free from Google.
  • Mirg shows which of these are installed, under the phone icon.

Mirg lists what is installed and what is missing under "See what's installed" on its home screen. If you ask for a phone game without the tools for it, it tells you what to get and offers to build a web game instead.

Good to know

  • A first iOS build takes a few minutes, because Xcode compiles the app.
  • Selling in the App Store needs an Apple Developer membership, which Apple charges for.

Questions

Is it a real app or just a website?

A real, installable app. The game is written with web technology and wrapped in a native iOS or Android app, with its own Xcode or Android Studio project.

Can Mirg publish to the App Store for me?

No. Submitting to the App Store or Google Play is done by you, from Xcode or Android Studio, with your own developer account. Mirg builds the app and the project you submit.

Do I need a Mac to make an iPhone app?

Yes. Apple's tools for building iPhone apps only run on a Mac, and Mirg runs on Mac today.
