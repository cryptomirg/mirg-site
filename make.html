Questions

Do I need to know how to code?

No. You describe the game in plain words, and the AI writes and fixes the code. You can look at the code if you're curious, but you never have to.

Is it free?

Yes, to try. Sign in with your email and start making a game, with no card needed. If you want to make more, plans start at $20 a month. See pricing.

What kinds of games can I make?

Platformers, shooters, puzzles, racing, card games, 3D games and more. They run in a web browser and on phones. Mirg also works with Godot, Unity, Roblox and other engines if you use them.

Which computers does it run on?

Mac (macOS 12 or later) and Windows 10 and 11. The games you make play on any computer or phone.
