A real example

This is a real session, not a mock-up: the request as it was typed, and what the agent did.

Make a Minecraft mod that adds a ruby ore, a ruby gem, and a ruby sword that sets enemies on fire
  1. Checked which Java and modding tools were installed
  2. Set up a Fabric mod project for the current version of Minecraft
  3. Wrote the ore, the gem and the sword, with their recipes, textures and world generation
  4. Compiled the mod
  5. Started a test server with the mod loaded. It ran with no errors, and ruby ore generated underground.
  6. That test caught one real problem, a change in the newest Minecraft version, which it fixed

The first message took 4 minutes 52 seconds.

The result. A working mod: ruby ore that spawns underground, a ruby gem, and a ruby sword crafted like a diamond one that sets what it hits on fire for five seconds. The finished mod is a single file you can add to a normal Fabric install.

How it works with Minecraft mods

  • The agent writes a standard Fabric mod in Java, with Gradle. It also works with Forge and NeoForge projects.
  • Mirg picks the right version of Java for your Minecraft version.
  • Running the mod starts a development copy of Minecraft, downloaded by the modding tools. You do not need to own the game to test a mod this way.
  • The agent could not check the fire effect, because that needs someone in the game hitting a mob, and it said so. Tried by hand, it worked.

What you need

  • Java 21 or newer, free.
  • That is all. The modding tools download what else they need the first time.

Mirg lists what is installed and what is missing under "See what's installed" on its home screen. If you ask for a Minecraft mod without the tools for it, it tells you what to get and offers to build a web game instead.

Good to know

  • The first build downloads the modding tools and a test copy of the game, and can take several minutes.
  • Resource packs and data packs need no Java at all, and Mirg can make those too.

Questions

Do I need to own Minecraft to make a mod?

Not to build and test one. The modding tools download a development copy of the game. To play the mod in your own worlds you need Minecraft: Java Edition and Fabric.

Which mod loader does it use?

Fabric for new mods. If you open an existing Forge or NeoForge project, the agent works in that.

Does it work with Bedrock Edition?

Mirg can write Bedrock add-ons, which are made of JSON files and scripts. The example on this page is a Java Edition mod.
