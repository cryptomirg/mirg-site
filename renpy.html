A real example

This is a real session, not a mock-up: the request as it was typed, and what the agent did.

Make a Ren'Py visual novel: a short mystery with two characters and two different endings
  1. Checked that Ren'Py was installed
  2. Wrote the story script, the character and image definitions and the game's settings
  3. Ran Ren'Py's built-in checker, which found no problems
  4. Launched the game, which reached its main menu with no errors

The first message took 2 minutes 47 seconds.

The result. The Stopped Clock: a detective caught in a storm at a mountain inn, and an innkeeper whose gold watch has gone missing. You choose where to look for clues, then name the thief. Find enough evidence and the culprit confesses; accuse without it and they get away.

How it works with Ren'Py

  • The agent writes .rpy script files, the same ones you would write by hand, so the story is easy to read and edit.
  • Ren'Py's own lint tool checks the script for mistakes before the game is run.
  • Backgrounds and characters start as simple shapes, so the story is playable at once. Drop your own images into the images folder, or ask for generated art.
  • The game opens in its own window. Play through the branches yourself: it is the best test of a story.

What you need

  • The Ren'Py SDK, free, about 150 MB. Unzip it and put the folder in Applications.

Mirg lists what is installed and what is missing under "See what's installed" on its home screen. If you ask for a visual novel without the tools for it, it tells you what to get and offers to build a web game instead.

Good to know

  • The agent can check that the script is valid. Whether the story is any good is for you to judge.

Questions

Can I change the story afterwards?

Yes. Ask for the change in plain words, or open the script file and edit it. Ren'Py scripts read almost like a screenplay.

Can it add my own artwork?

Yes. Put image files in the game's images folder, named to match each scene or character, or ask Mirg to generate art.

Can I release the game?

Yes. Ren'Py builds versions for Windows, Mac and Linux from its own launcher.
