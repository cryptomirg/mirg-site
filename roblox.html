A real example

This is a real session, not a mock-up: the request as it was typed, and what the agent did.

Make a Roblox obby: five platforms to jump across, a checkpoint in the middle, and a finish line that shows a "You win" message
  1. Checked that Roblox Studio and the Rojo build tool were installed
  2. Wrote the project file that lays out the course: a spawn pad, five coloured platforms, a checkpoint, a finish line and a floor below to catch falls
  3. Wrote the script for the checkpoint, the win message and resetting a player who falls
  4. Built the place file and opened it in Roblox Studio

The first message took 54 seconds.

The result. A working obby: spawn, jump across five platforms, respawn at the checkpoint, and a You win message at the end.

How it works with Roblox

  • Roblox games run only in Roblox Studio or the Roblox app, so the agent cannot see or play them. It builds the game and you press Play.
  • Because it cannot play, it checks its work another way: it builds the place as a readable file and confirms each part is where it was meant to be.
  • That check exists because of a real mistake. In the first version of this example every part loaded stacked in one spot, and the player died on spawning. Told only that, the agent found the cause, fixed it and verified every position.
  • Code is Luau, in ordinary files. The Rojo tool turns the project into a Roblox place.

What you need

  • Roblox Studio, free, with a Roblox account.
  • Rojo, a small free build tool. Mirg installs it for you with one button.

Mirg lists what is installed and what is missing under "See what's installed" on its home screen. If you ask for a Roblox game without the tools for it, it tells you what to get and offers to build a web game instead.

Good to know

  • You are the playtester. Tell the agent what you see in Studio and it will fix it.
  • Publishing to Roblox is done from Roblox Studio.

Questions

Can the agent test my Roblox game?

Not by playing it: Roblox games only run inside Roblox Studio. It checks that the game builds and that every part is where it should be, and you press Play in Studio to try it.

Do I need Roblox Studio?

Yes, to open and play the game. It is free. Mirg also uses a small free tool called Rojo, which it can install for you.

What language are the scripts in?

Luau, the language Roblox uses. The scripts are ordinary files you can read and edit.
