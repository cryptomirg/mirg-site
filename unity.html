A real example

This is a real session, not a mock-up: the request as it was typed, and what the agent did.

Make a Unity game: a 3D ball that rolls around a platform collecting coins, with a score counter
  1. Checked that Unity was installed, and which version
  2. Wrote four C# scripts: the player, the coins, the score and the camera
  3. Wrote an editor script that builds the scene in code: the platform, walls, the ball and 14 coins
  4. Ran Unity from the command line to build the game. The build finished with no errors.
  5. Launched the game, then looked at the window and rolled the ball to collect a coin

The first message took 2 minutes 50 seconds.

The result. A 3D Unity game built and compiled into a Mac app: a ball that rolls with physics, 14 spinning coins, a score counter and a camera that follows. The agent played it in its window and collected coins.

How it works with Unity

  • The agent writes C# under Assets, as in any Unity project. It does not write scenes by hand, which is easy to get wrong; it writes a small editor script that builds the scene, and has Unity run it.
  • Unity builds the game from the command line. A build takes a minute or more.
  • The game opens in its own window. The agent takes screenshots of that window and sends key presses to it.
  • The project opens in the Unity editor as usual.

What you need

  • Unity Hub and a Unity editor, free for personal use, with a Unity account. About 12 GB.
  • Open the Unity editor once yourself first, so that your licence is active.
  • To let the agent see and play the game's window, macOS asks for two permissions, once.

Mirg lists what is installed and what is missing under "See what's installed" on its home screen. If you ask for a Unity game without the tools for it, it tells you what to get and offers to build a web game instead.

Good to know

  • The agent works through code and the command line. It does not click around the Unity editor.
  • Builds are slower than web or Godot games, so each change takes longer to check.

Questions

Does it work with my existing Unity project?

Yes. Open the project's folder in Mirg and ask for a change. The agent edits the C# scripts and can build the game to check it.

Which version of Unity do I need?

A current Unity editor installed through Unity Hub. Mirg finds the editor that matches your project, or the closest one installed.

Can the agent see my Unity game?

Yes. The game opens in its own window, and once you allow it in macOS, the agent takes screenshots of that window and presses keys in it.
