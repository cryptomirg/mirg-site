A real example

This is a real session, not a mock-up: the request as it was typed, and what the agent did.

Make an Unreal game: a third-person character that can run and jump around a small level with a few platforms
  1. Checked that Unreal Engine was installed, and looked at the templates that come with it
  2. Started the project from Unreal's Third Person template, for the character, its animations and the camera
  3. Wrote a script that builds the level inside the editor: a floor with walls, six rising platforms, a ramp, stairs and crates, with sky and lighting
  4. Ran the script and confirmed every platform was at its planned position
  5. Launched the game. It stopped, because a piece of Apple's developer tools was missing. The agent explained the problem and gave the one command to fix it, without installing anything itself.

The first message took 7 minutes 37 seconds.

The result. A third-person Unreal game with a character that runs and jumps across a level of platforms. After the missing Apple component was installed, the game ran.

How it works with Unreal Engine

  • Most Unreal game logic lives in Blueprints, which are binary files an AI cannot read or write. The agent works in C++ and Python, and starts from Unreal's own templates for things like the character.
  • Levels are built by a script that runs inside the Unreal editor, so the layout is described in a file you can read and change.
  • The first launch compiles shaders and takes several minutes before a window appears.
  • The game opens in its own window, which the agent can look at and play once macOS allows it.

What you need

  • Unreal Engine 5, through the Epic Games Launcher, with an Epic Games account. 60 to 100 GB.
  • Xcode, and Apple's Metal Toolchain. Mirg checks for the toolchain and can install it with one button.
  • Open Unreal once from the launcher first, so it finishes its own setup.

Mirg lists what is installed and what is missing under "See what's installed" on its home screen. If you ask for a Unreal game without the tools for it, it tells you what to get and offers to build a web game instead.

Good to know

  • Unreal is the slowest platform to work with here: big downloads, long first compiles, and no access to Blueprints.
  • For a first game, a web game or Godot will get you playing much sooner.

Questions

Can the agent edit Blueprints?

No. Blueprints are binary files that cannot be read or written as text. The agent writes C++ and Python, and uses Unreal's own templates where a Blueprint is needed.

Why did my Unreal game stop as it started?

On a Mac, Unreal needs Apple's Metal Toolchain to compile shaders, and recent versions of Xcode do not install it by default. Mirg checks for it and offers a button to install it.

How long does an Unreal game take to build?

The example on this page took about seven and a half minutes for the first message. The first launch of any Unreal project adds several minutes while shaders compile.
