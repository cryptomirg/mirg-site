A real example

This is a real session, not a mock-up: the request as it was typed, and what the agent did.

A top-down zombie survival shooter with waves, three weapon types, upgrades between waves, and a boss every fifth wave
  1. Wrote the game as five small files: the page, the world and enemies, the effects, the upgrades and the main loop
  2. Started the game in the Game tab
  3. Played it three times, moving and shooting, and read the game's own numbers after each to check waves, weapons and score
  4. Reported what it had checked and how to play

The first message took 4 minutes 20 seconds.

The result. A complete wave shooter, 626 lines across five files, playable straight away. Follow-up messages changed it in seconds: the same approach built a fox platformer and then added a double jump, a walking enemy and generated artwork, one request at a time.

How it works with Web games

  • The game runs in Mirg's Game tab, next to the chat. Edit a file and it reloads.
  • The agent takes screenshots, presses keys and clicks, and reads exact values such as positions and score, so it tests behaviour and not just whether the page loads.
  • Games are plain files: HTML and JavaScript, using Canvas for 2D or Three.js for 3D. You can open them in any editor or put them on any web host.
  • Artwork starts as clean shapes drawn in code, so the game is playable at once. Ask for real art when you want it.

What you need

  • Nothing. Web games work the moment Mirg is installed.

Mirg lists what is installed and what is missing under "See what's installed" on its home screen. If you ask for a web game without the tools for it, it tells you what to get and offers to build a web game instead.

Good to know

  • A web game is the fastest way to try an idea, and the starting point for a phone app.
  • Very large 3D games are better suited to an engine such as Godot or Unity.

Questions

Do I need to know how to code?

No. You describe what you want in plain words and the agent writes the code. The code is there in the Code tab if you want to read or change it.

Can I put the game on my own website?

Yes. A web game made with Mirg is a folder of ordinary files that any web host can serve.

Can it make 3D games?

Yes. The agent uses Three.js for 3D web games and plain Canvas for 2D.
